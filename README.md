# Gadget Galaxy - Java OOP Inventory & Sales Management System
Gadget Galaxy is a desktop-based Inventory and Sales Management System developed using Pure Java, Java Swing, JDBC, and MySQL. The system is designed for an electronics retail store to manage products, inventory, sales transactions, and user accounts efficiently.  The project demonstrates core and advanced Object-Oriented Programming concepts including encapsulation, inheritance, polymorphism, abstraction, interfaces, multithreading, exception handling, collections framework usage, and file handling.  The application follows MVC architecture and includes role-based authentication for Store Managers and Sales Representatives, real-time inventory management, invoice generation, sales tracking, and reporting functionalities.  Technologies Used: - Java 17+ - Java Swing - MySQL - JDBC - MVC Architecture - File Handling - Java Collections Framework - Multithreading
